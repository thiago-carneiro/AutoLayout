## English (en-US)

**Short description**

The right keyboard layout for the keyboard you are using: AutoLayout switches the Windows default layout when an external keyboard is connected or disconnected.

**Description**

Windows has one keyboard layout at a time, not one per keyboard. If your laptop's keyboard is US-International and your desk keyboard is Brazilian ABNT2, or German, or Japanese, you end up pressing Win+Space all day, and Windows switches back to its default after the lock screen anyway.

AutoLayout sits in the notification area and sets the Windows default keyboard layout according to the keyboards connected. With no external keyboard, you get your default layout. Connect a keyboard you set up, and you get its layout. Connect one for the first time, and AutoLayout asks which layout it has, with a suggestion when it can make one; nothing changes until you answer.

Because it is the default layout that changes, new windows and the session after the lock screen get the right layout too. Win+Space keeps working as usual.

When someone uses the PC through Remote Desktop, Windows uses the layout of the remote computer's keyboard, and AutoLayout stays out of the way.

AutoLayout never reads what you type: it does not hook, record or inject keystrokes. It makes no network connections and has no telemetry. It is free and open source (Apache 2.0).

**Features**

- Switches the Windows default keyboard layout when external keyboards are connected or disconnected
- Asks for the layout of each new keyboard, once, and remembers it
- Works with USB and Bluetooth keyboards; ignores mice and receivers you mark
- Leaves Remote Desktop sessions to the remote computer's layout, or uses one you choose
- Never reads what you type; no network access, no telemetry
- Available in 38 languages; free and open source

## Português (pt-BR)

**Descrição curta**

O layout certo para o teclado que você está usando: o AutoLayout troca o layout padrão do Windows quando um teclado externo é conectado ou desconectado.

**Descrição**

O Windows tem um layout de teclado por vez, não um por teclado. Se o teclado do notebook é US-Internacional e o da mesa é ABNT2, você passa o dia apertando Win+Espaço, e o Windows volta ao padrão depois da tela de bloqueio de qualquer jeito.

O AutoLayout fica na área de notificação e define o layout padrão do Windows conforme os teclados conectados. Sem teclado externo, vale o seu layout padrão. Conecte um teclado já configurado, e vale o layout dele. Conecte um pela primeira vez, e o AutoLayout pergunta qual é o layout, com uma sugestão quando consegue fazer uma; nada muda até você responder.

Como é o layout padrão que muda, as janelas novas e a sessão depois da tela de bloqueio também ficam com o layout certo. O Win+Espaço continua funcionando como sempre.

Quando alguém usa o PC pela Área de Trabalho Remota, o Windows usa o layout do teclado do computador remoto, e o AutoLayout não interfere.

O AutoLayout nunca lê o que você digita: não intercepta, não grava e não injeta teclas. Não faz conexões de rede e não tem telemetria. É gratuito e de código aberto (Apache 2.0).

**Recursos**

- Troca o layout padrão do Windows quando teclados externos são conectados ou desconectados
- Pergunta o layout de cada teclado novo uma vez e se lembra dele
- Funciona com teclados USB e Bluetooth; ignora mouses e receptores que você marcar
- Na Área de Trabalho Remota, deixa valer o layout do computador remoto, ou usa um que você escolher
- Nunca lê o que você digita; sem acesso à rede, sem telemetria
- Disponível em 38 idiomas; gratuito e de código aberto
